# Exercices et travaux

Dossier pour les exercices personnels et d’éventuels travaux. L’étude du livre peut se faire sans inscription au cours ni calendrier d’examens.

Organisation possible : `NN-sujet/enonce.md`, `notes.md`, `solution.md`, `notebook.ipynb`.

**Dépôt public** : ne pas publier d’énoncés privés, de corrigés non autorisés, de soumissions évaluées ou d’informations personnelles. Utiliser `Assignments/private/` pour le travail qui ne doit pas être suivi par Git.
