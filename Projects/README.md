# Projets et expériences

Un sous-dossier par expérience : `nom/README.md`, `src/`, `notebooks/`, `results/`.

Pour chaque expérience, documenter :

- l’objectif et le chapitre lié ;
- les variables d’état, actions, dynamique et observations ;
- la récompense ou le coût, l’horizon et les contraintes ;
- les données et leurs permissions ;
- les dépendances, graines aléatoires et commandes de reproduction ;
- les résultats et limites constatées.

Ne pas modifier les expériences originales dans `ebook/` pour prendre des notes : travailler sur une copie ou un nouveau projet ici.
