# Notes personnelles

Conserver ici les notes, reformulations et questions, séparées du texte original.

Convention suggérée : `NN-sujet.md`, avec le même numéro que le [sommaire du livre](../Content/README.md).

- [Modèle de note](TEMPLATE.md).
- [Questions à revoir](QUESTIONS.md).

Chaque note devrait préciser le chapitre et la section, distinguer les explications du professeur des interprétations personnelles, et conserver les questions encore ouvertes. Les fichiers de ce dossier sont **publics**, sauf ceux placés dans `Notes/private/`.
