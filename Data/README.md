# Données

Dossier réservé aux futures données des expériences personnelles. Les données originales du livre sont déjà présentes dans le clone `ebook/data/`.

Avant d’ajouter un jeu de données, préciser son URL, sa version/date, son attribution, sa licence, son format et la procédure de préparation.

- Conserver les petits exemples publics et leurs métadonnées.
- Ne pas committer de données personnelles, confidentielles ou volumineuses.
- Utiliser `Data/private/` pour les fichiers locaux exclus de Git.
- Ne pas ajouter de données Mila privées simplement parce que le dépôt est lié à ce livre.
